# Trail

Claude와 나눈 대화에서 **기록하기로 한 내용**을 프로젝트 → 활동 → **STAR(상황·과제·내가 한 일·결과)** 트리로 자동 정리하고, 내가 모든 필드를 바로 고칠 수 있으며, 제출용 **STAR 문서**로 내려받게 해 주는 나 한 명만 쓰는 웹 앱입니다.

> 모든 것은 먼저 자동으로 만들고, 내가 그 위에서 언제든 고칩니다. 내가 고친 필드는 잠겨서 이후 기록이 덮어쓰지 않습니다.

- **공개 주소**: https://trail-pink-zeta.vercel.app — 로그인 전에는 지어낸 가상 샘플만 보입니다.
- **저장소**: https://github.com/Jeewoo-Jung/trail

## 무엇을 하나

- **Claude가 직접 기록합니다.** Claude에 이 앱을 커스텀 커넥터(원격 MCP 서버)로 연결하면, 같은 주제에서 내 메시지가 5개 이상이고 결정·산출물이 있을 때(주제당 1회, 대화당 최대 3회) 기록 여부와 위치(이어붙일 활동·새 활동)를 한 번에 묻고, 답에 따라 활동 카드(STAR)를 앱으로 보냅니다. 항목마다 주체(내가 한 일·내 계획·Claude 제안 미확인·추정)와 근거(대화 제목·날짜·원문 발췌)가 붙고, 근거가 없는 항목은 비워 둡니다.
- **자동 병합과 잠금.** 기존 활동에 새 기록이 들어오면 내가 고친(잠긴) 항목은 건드리지 않고 새 내용을 필드별 "제안"으로 따로 보여 줍니다. 잠기지 않은 항목은 덧붙기만 합니다.
- **트리 뷰에서 바로 고칩니다.** 이름·종류·상태·기간·설명·STAR 항목·근거·산출물을 인라인으로 편집하고, 노드 이동·활동 합치기/쪼개기·수동 추가, 삭제(휴지통 복구), 제외(삭제가 아닌 상태, 부모 제외 시 자식도 함께)를 지원합니다.
- **상향식 묶기.** 같은 위치에 같은 종류의 노드가 쌓이면 새 상위 노드를 한 단계씩 제안하고(버튼을 눌렀을 때만 Claude 호출), 내가 승인한 것만 반영합니다. Claude API 키가 없으면 이 기능만 꺼집니다.
- **결과·최종 산출물 등록.** 앱과 Claude 채팅 어느 쪽에서 입력해도 같은 칸이 갱신됩니다. 오래 기록이 없고 결과가 빈 활동은 "결과 등록 대기"로 보여 주며, 파일은 브라우저가 Supabase Storage에 직접 올립니다.
- **STAR 문서.** 프로젝트·활동 단위로 문서를 보고 Markdown / JSON으로 내려받습니다. 제외·휴지통 노드는 자동으로 빠집니다. 마인드맵은 보조 화면입니다.
- **공개 샘플.** 로그인 전에는 지어낸 가상 노드·문서만 보이고, 내 데이터는 로그인(또는 커넥터 OAuth) 없이는 읽거나 쓸 수 없습니다.

## 화면

| 주소 | 설명 |
|---|---|
| `/` | 로그인 전 가상 샘플 화면(트리 + STAR 문서 미리보기) |
| `/login` | 이메일 로그인 (신규 가입은 막혀 있음) |
| `/my` | 내 기록: 노드 트리, 인라인 편집, 제안, 묶기 제안, 결과 등록 대기, 휴지통 |
| `/my/documents` | STAR 문서 뷰와 내려받기(프로젝트·활동 단위) |
| `/my/mindmap` | 마인드맵(보조, 읽기 전용) |
| `/my/settings` | 결과 등록 대기 일수 |
| `/oauth/consent` | Claude 커넥터 연결 승인 화면 |
| `/api/mcp` | Claude 전용 접수 창구(원격 MCP: `list_cards`, `record_cards`, `record_result`, `get_record_rules`) |
| `/api/export` | STAR 문서 내려받기(로그인 필요, `scope`·`format`) |

## 기술 스택

Next.js 16 (App Router) · React 19 · TypeScript(strict) · Tailwind CSS 4 · Supabase(Postgres + Auth + OAuth 2.1 서버, RLS "내 행만") · Claude API(`claude-haiku-5-5`) · `mcp-handler` · zod · Vitest · Vercel

## 폴더

```
app/          화면과 API (app/api/mcp = 원격 MCP 서버)
components/   화면 조각 (노드 트리, 상세 편집, STAR 문서, 마인드맵 등)
lib/rules/    순수 규칙: 노드·STAR 한도 검사, 병합·제외·묶기·결과 대기, 문서 만들기, 비밀값 가리기, 그래프 배치 (+ 테스트)
lib/mcp/      활동 기록·병합·조회·결과 저장, 호출 횟수·크기 제한, 토큰 확인
lib/my/       내 화면의 편집 동작(노드·항목·근거·산출물·묶기·내려받기)
lib/claude/   Claude API 호출(묶기 제안)과 지시문
supabase/     마이그레이션(SQL)과 스키마 점검
instructions/ Claude 사용자 지침(기록 규칙)
```

## 로컬 실행

```bash
npm install
cp .env.example .env.local   # 값을 채운다 (아래 변수 이름 참고)
npm run dev
```

필요한 환경변수 이름만 적습니다(값은 `.env*`에 두고 저장소에는 올리지 않습니다).

| 이름 | 용도 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Supabase 연결(공개용 값) |
| `ANTHROPIC_API_KEY` | 상향식 묶기 제안 (서버 전용, 없으면 이 기능만 꺼짐) |
| `OWNER_USER_ID` | 이 앱의 주인 계정 번호. 이 계정만 로그인·커넥터 승인 가능 |

## 보안 메모

- 키·토큰은 서버 환경변수에만 두고 브라우저로 보내지 않습니다. 서버 로그에는 대화·노드 내용을 남기지 않습니다. 내 실제 데이터 백업(`backups/`)은 저장소에 올리지 않습니다.
- 모든 표와 첨부 파일 버킷(`trail-files`, 비공개)에 "내 것만" 접근 규칙을 걸었고, 커넥터 요청은 20KB·분당 30회·하루 500회로 제한합니다.
- 노드·대화 속 문장은 Claude에게 "분석할 자료"로만 전달하고, 지시로 따르지 않게 막았습니다.
